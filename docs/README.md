# Atlas del Paisaje Histórico y Líneas Ley

Visualizador cartográfico interactivo 100% estático.

## Ver Mapa en Vivo
Accede al mapa interactivo directamente en [GitHub Pages](https://tu-usuario.github.io/Atlas/).

## Características
- **Megalitos y Construcciones Medievales**: Coordenadas geográficas exactas en Europa.
- **Vórtices Tectónicos y Líneas Ley v7**: Red de corrientes telúricas onduladas según accidentes geológicos.
- **PWA Offline**: Compatible con teléfonos móviles y tablets.

## Deploy local
```bash
python -m http.server 8080
```
Abrir `http://localhost:8080`
